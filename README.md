# RealDice 3D

RealDice 3D is a motion-responsive Android dice simulator by Haselton Media Group.

## Current prototype
- Shake phone to roll
- Flick/throw gesture to roll
- Tap to roll
- Force-responsive tumble animation
- Haptic and audio impact feedback
- AdMob test banner integration
- Automated GitHub Actions APK/AAB builds

Package: `com.haseltonmediagroup.realdice3d`

## Roadmap
The current version establishes the native Android sensor/input and monetization foundation. The premium phase will replace the stylized prototype die with a true GPU-rendered 3D scene, physically based materials, rigid-body-style collision behavior, multiple dice, selectable surfaces, spatial rolling/impact audio, settings, consent/privacy handling, and production AdMob IDs.

## Advertising
The repository intentionally uses Google's official test AdMob identifiers. Production IDs must be inserted before Play Store release.
